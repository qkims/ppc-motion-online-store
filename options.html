Hero visuals

Motion Direction 1 ( New Visuals ) — Figma section 74:42950. Three 840×630 frames sharing one store-builder kit, numbered left to right as they sit on the canvas. 840×630 is this library’s hero-image format, and the template’s hero slot (50:15634) renders one at 511 × 383.25 — exactly 511/840 — so each of these drops straight into the page. See the Option 1/2/3 tabs for that.

The hero-store-builder-* name inside each frame is inherited from whichever component was duplicated as a starting point and does not describe its imagery — the frame named “fashion” holds the beauty visual and the one named “health” holds the fashion visual. The numbering above is canvas order, which is the only ordering the file actually asserts.
